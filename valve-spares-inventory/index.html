Getting started

  1. Add your valves.
  2. Create each spare part once, then link it to every compatible valve.
  3. Enter barcodes and count physical stock using a scanner or keyboard.
  4. Select the parts and quantities required for an overhaul.
  5. Export regular JSON backups. Import a backup on another device to transfer the data.

Local storage is not shared or automatically synchronized between devices. Keep backups in a safe location.
